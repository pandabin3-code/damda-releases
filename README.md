# 담다 Beta 0.5.0-beta.9

처음 연결할 때 막히는 부분을 앱 안에서 점검할 수 있도록 도움말과 해결 버튼을 추가했습니다. 업데이트 중 메시지 수집이 겹치거나 설치 실패 후 다시 시도하기 어려웠던 흐름도 개선했습니다.

- 왼쪽 **도움말 · 문제 해결**에서 메시지함 위치, 자동 가져오기 준비, 최근 결과, 첨부파일 폴더를 확인할 수 있습니다.
- 메시지함이 없거나 여러 개일 때 다음 행동을 안내합니다. 진단만으로 설정을 바꾸거나 원본 메시지함을 열지 않습니다.
- 첨부파일 경로를 직접 입력하는 대신 **폴더 선택**으로 적용할 수 있습니다. 취소하면 기존 설정을 유지합니다.
- 업데이트를 준비하는 동안 새 메시지 수집을 잠시 멈추고, 진행 중인 수집이 끝난 뒤 설치를 이어갑니다. 기다리는 동안 **나중에 설치**를 선택할 수 있습니다.
- 설치 실패·취소 후 **업데이트 다시 시도** 버튼을 사용할 수 있도록 상태 확인을 개선했습니다.
- 이름이 ‘담다 Beta’인 기존 창도 설치 도우미가 정상적으로 찾아 종료를 요청하도록 수정했습니다. 강제 종료하지 않습니다.
- [화면으로 보는 사용법 · 문제 해결 가이드](https://pandabin3-code.github.io/damda-releases/help.html)를 공개했습니다.

기존 업무와 설정을 유지합니다. 편집 중인 내용은 먼저 저장해 주세요.

**이전 버전에서 이미 업데이트가 멈췄다면:** 오류 창과 설치 창을 닫고 메시지 가져오기가 끝날 때까지 기다리세요. 담다의 ‘앱 종료’를 누른 뒤 이번 설치 파일을 직접 실행해 주세요. 기존 업무를 삭제할 필요는 없습니다. 가져오기가 계속 끝나지 않으면 강제로 종료하지 말고 오류 문구를 알려주세요.

[담다 Beta 설치 파일](https://github.com/pandabin3-code/damda-releases/releases/download/v0.5.0-beta.9/Damda-Beta-Setup-0.5.0-beta.9-x64.exe)

WebView-Preview 파일명은 기존 자동 업데이트를 위한 호환용이며 Beta 설치 파일과 내용이 같습니다. 브라우저판을 쓰는 분은 Damda-Setup 파일을 사용하세요.
