## 새로 추가·개선된 기능

- 학교 이름을 검색하고 자동완성 목록에서 선택하면 급식을 조회할 수 있습니다. 급식 카드에서 학교명·날짜·끼니를 확인하고 메뉴와 영양 정보를 봅니다. 설치본의 급식 연결 설정 누락으로 학교 검색이 실패하던 문제도 수정했습니다.
- 확인한 안내는 체크 애니메이션 뒤 미처리 카드 아래로 이동합니다. 확인을 취소하면 기존 순서로 돌아옵니다. 이는 담다 안의 안내 확인 상태입니다.
- NEW 배지를 카드 테두리에 배치하고 검색·필터·날짜 이동 버튼의 간격을 정돈했습니다. 달력·급식·하단 일정이 본문과 함께 스크롤됩니다.
- beta.40에서 개선한 미완료 업무 우선·최근 완료순 정렬, 일괄 완료·안내 확인, 날씨 출처·지역·예보 시각 표시를 이어갑니다.

## 설치와 검증 범위

기존 앱에서 **업데이트 확인 → 자동 업데이트**를 선택하거나 위 설치 파일을 받아 설치하세요. 업데이트는 사용자 선택으로 시작하며 강제 설치하지 않습니다. 직접 설치할 때는 미저장 내용을 저장하고 담다의 **앱 종료**로 정상 종료한 뒤 진행하세요. 기존 업무와 설정은 유지합니다.

beta.44 공개 기록 기준으로 합성 검사 469개와 화면 회귀 검사, 포장된 실행 파일의 실제 공개 학교 검색·급식 조회를 확인했습니다. beta.40에서 beta.44로 신규 설치·업그레이드·자동 재실행·재설치, 업무·설정 보존 및 제거 후 저장소 보존을 확인했습니다.

**실제 메신저 백업 실행·읽음 변경·첨부 다운로드·모바일 읽음 상태는 이번 검증 범위에 포함되지 않았습니다.** 자동 읽음 연동은 비활성입니다. 실제 UAC 승인과 다른 관리자 계정은 이번에 재검증하지 않았으며, 환경별 WebView 시작·종료 지연 가능성이 남아 있습니다. 종료 중에는 잠시 기다려 주세요. 자세한 제한은 릴리스 설명을 확인하세요.

코드 서명 없는 베타 설치 파일입니다. 파일명의 WebView-Preview는 기존 설치·업데이트 호환 이름이며 별도 제품이 아닙니다.
