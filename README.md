# 담다 Beta 0.5.0-beta.17

Daily Assistant for Messaging & Data Archive

선생님의 하루를 담다. 기존 공개판 beta.9 이후의 개선을 함께 제공합니다.

## 달라진 점

- 진행 중·재검토·시작 전·완료로 바꾸면 상태에 맞는 짧은 효과를 보여줍니다. 홈 카드와 자세히보기에서 같은 아이콘과 문구를 사용합니다. 애니메이션을 줄인 PC에서도 상태 확인은 표시합니다.
- 카드의 삭제와 전체 업무 완료, 완료 되돌리기를 다듬었습니다. 전체 완료는 확인 후 처리하며, 되돌리기 알림은 최대 3개까지만 잠시 나타납니다. 상세 화면에서도 되돌릴 수 있습니다.
- 자세히보기에서 이전·다음 메시지로 이동할 수 있습니다. 수정 내용은 저장 후 이동하고, 저장에 실패하면 입력을 유지합니다.
- 메시지함 파일이 여러 개일 때 본인 메시지함을 찾아 선택하기 쉽게 개선했습니다.
- 메시지 가져오기의 처리 구조를 개선하고, 가져오는 중에도 앱 종료 요청을 처리하도록 보완했습니다.
- 답장에 인용된 이전 대화가 자동 제목·요약에 섞이는 문제를 개선했습니다.
- 테마 설정을 추가했습니다. 기본은 날씨에 맞는 은은한 배경이며, 배경 종류와 농도·움직임을 바꿀 수 있습니다.
- 앱 실행 시 업데이트 소식을 확인할 수 있습니다. ‘오늘 보지 않기’, ‘다시 보지 않기’를 지원하며 설정에서 이전 기록도 다시 볼 수 있습니다.

## 업데이트 방법

기존 앱에서 새 버전 안내가 나타나면 **자동 업데이트**를 눌러 주세요. 다운로드와 설치가 이어집니다. 편집 중인 내용은 먼저 저장해 주세요. 기존 업무와 설정은 유지합니다.

업데이트 안내는 앱 실행 시와 사용 중 주기적으로 확인합니다. 바로 확인하려면 설정의 **업데이트 확인**을 이용해 주세요. 설치는 사용자 선택으로 시작하며, 모든 PC에 강제로 설치하지 않습니다.

자동 업데이트를 지원하지 않는 오래된 버전이나 회사·학교 네트워크에서 다운로드가 막힌 경우, 아래 설치 파일을 받아 한 번 설치해 주세요.

- **일반 프로그램형 권장:** `Damda-Beta-Setup-0.5.0-beta.17-x64.exe`
- **기존 브라우저형 사용자:** `Damda-Setup-0.5.0-beta.17-x64.exe`
- `Damda-WebView-Preview-Setup-0.5.0-beta.17-x64.exe`는 기존 자동 업데이트 주소와의 호환을 위한 파일명이며 권장 설치본과 내용이 같습니다. 화면 이름은 담다 Beta입니다.
