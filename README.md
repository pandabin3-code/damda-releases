# 담다 DAMDA

**Daily Assistant for Messaging & Data Archive**

선생님의 하루를 담다. 메시지 속 요청을 업무 카드로 정리하고, 원문을 확인하며 마감과 완료를 관리하는 Windows 앱입니다.

[최신 설치 파일과 변경 사항](https://github.com/pandabin3-code/damda-releases/releases) · [오류 보고](https://github.com/pandabin3-code/damda-releases/issues/new)

## 설치

최신 **0.5.0-beta.4**에는 D+체크 아이콘, 왼쪽 메뉴의 버전 표시, 날짜 위 업무 점과 자동 업데이트 버튼이 포함됩니다. beta.3 이하에서는 이번 설치 파일을 한 번 직접 실행하고, beta.4부터 다음 버전은 자동 업데이트 버튼으로 다운로드·검증·설치·재실행을 진행할 수 있습니다.

일반 프로그램 창은 `Damda-WebView-Preview-Setup-…-x64.exe`를 받으세요. `Damda-Setup-…-x64.exe`는 브라우저 방식의 대체 설치본입니다. Python은 필요하지 않습니다. WebView2 런타임이 없는 경우 설치 과정에서 인터넷 연결이 필요합니다.

편집 내용을 저장하고 새 설치 파일을 실행하면 기존 앱에 정상 종료를 요청한 뒤 업데이트합니다. 가져오기나 동기화가 진행 중일 때는 완료 후 다시 설치하세요. 저장된 업무와 설정은 유지합니다. 앱 시작 시와 사용 중 약 6시간 간격으로 버전을 확인하고 새 버전 알림을 표시합니다. 다운로드와 설치는 사용자가 진행합니다.

자동 종료 요청은 WebView 설치본에서 지원합니다. 브라우저 대체 설치본은 앱의 `앱 종료`를 먼저 눌러 주세요. 탭만 닫는 것으로는 백엔드가 종료되지 않을 수 있습니다.

## 제공 기능

- 한 메시지에 한 카드, 최신 수신순 정렬, 전체 대상 검색·분류·마감 필터
- 카드에서 분류·상태 빠른 변경, 완료 시각 기록과 월별 완료 목록
- 원문 확인, 첨부파일과 URL 연결, 담당·날짜 확인 표시
- 선택형 쿨메신저 연결과 최초 승인 후 자동 변경 감지
- Windows 사용자 계정에 연결된 암호화 저장
- beta 0.5: Google 캘린더 선택 업무 동기화 및 학교 급식 메뉴

Google 캘린더는 데스크톱 OAuth 설정과 Google 로그인이 필요한 단방향 수동 동기화입니다. 학교 급식은 나이스 인증키와 학교 선택이 필요합니다. 계정과 키가 없는 상태의 실제 서비스 연동은 검증 완료로 표시하지 않습니다. 설정하지 않으면 해당 서비스로 백그라운드 요청을 보내지 않습니다.

설치본은 코드 서명이 없는 베타입니다. 일반 사용자 계정의 자동 백업 설정은 전산 담당자의 도움이 필요할 수 있습니다. 모바일 동기화와 모바일 읽음 상태 보존은 현재 제공·보장 기능이 아닙니다.

## 오류와 개인정보

앱에서 준비한 진단 정보와 오류 상황을 확인한 뒤 GitHub에 제출해 주세요. 공개 이슈에 실제 메시지·이름·연락처·교정 데이터 파일을 올리지 마세요.

이 저장소는 공개 설치 파일·소개 자료·배포 안내용입니다. 개인 메시지와 업무 저장소, 로그인 토큰을 포함하지 않습니다.
