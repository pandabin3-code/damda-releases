Windows 64비트 설치형 베타입니다. 자동 판독은 로컬 규칙 기반이며 원문 확인이 필요합니다.
0.5.0-beta.44(2026.10.01)에는 학교 이름 자동완성 검색과 날짜·끼니별 급식 조회가 추가됐습니다. 학교를 선택하면 메뉴와 영양 정보를 확인할 수 있습니다. 확인한 안내는 미처리 카드 아래로 이동하고, 확인 취소 시 원래 순서로 돌아옵니다. 미완료 우선·최근 완료순 정렬과 일괄 완료·확인, 날씨 출처·지역·예보 시각 표시도 안내합니다. Google 캘린더와 개인 요약 교정 도구는 이번 공개 릴리스의 추가 기능에 포함되지 않습니다.

실제 메신저 백업 실행·읽음 변경·첨부 다운로드·모바일 읽음 상태는 beta.44 검증에 포함되지 않았고 자동 읽음 연동은 비활성입니다. 소개 화면은 beta.6, 도움말 화면은 beta.9의 합성 예시로 보존하며 최신 화면으로 표시하지 않습니다.

## 담다를 만들며

처음부터 지금의 담다는 아니었어요. 초기 TeacherInbox에서는 메시지를 직접 넣고, 제목과 기한을 검토했습니다. 할 일과 일정을 모아 보는 COOL 업무비서와 단순한 개인 작업 공간도 시도했습니다.

TaskCards에서는 메시지를 큰 카드에 담았습니다. 하지만 글자가 잘리지 않게 하자 카드가 길어졌고, 요청을 나누자 비슷한 카드가 반복되기도 했습니다. 그래서 지금은 메시지 하나를 카드 하나로 담고, 목록에서는 짧게, 필요할 때 원문을 펼쳐 보게 했습니다.

짧다고 늘 좋은 요약은 아니었습니다. 대상과 조건도 놓치지 않도록 근거를 남기고 직접 고칠 수 있게 했습니다. 담다는 아직 다듬는 중입니다. 다시 찾는 수고가 조금씩 줄어들기를 바랍니다.
