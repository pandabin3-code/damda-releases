# 페이지 제작 지침

이름: 담다 DAMDA / Daily Assistant for Messaging & Data Archive
대상: 쿨메신저의 요청을 놓치지 않고 관리하려는 선생님.
기존 흰색·푸른색 레이아웃과 넓은 여백, 기능별 화면 배치를 유지합니다.
핵심 순서: 업무 한눈에 → 원문과 편집 → 확인 필요 → 완료 기록 → 연결 → 저장과 오류 보고.
다운로드는 GitHub Releases로 연결합니다. 출시되지 않은 기능을 제공 중으로 표현하지 않습니다.
모든 이미지는 새 임시 저장소에 만든 가상 예시이며 개인정보를 포함하지 않습니다.
