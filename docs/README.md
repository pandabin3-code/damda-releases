# 담다 DAMDA 소개 페이지

index.html을 열면 됩니다. 기존 흰색·푸른색 디자인과 정적 HTML 구조를 유지합니다.
소개와 도움말의 기능 설명·설치 링크는 0.5.0-beta.44(2026-10-01) 공개 기록에 맞췄습니다.
학교 검색·급식 조회, 안내 확인·취소, 업무 정렬·일괄 처리와 날씨 표시를 안내합니다.

이미지는 images 폴더에 보존된 PNG입니다. 소개는 beta.6, 도움말은 beta.9의 합성 예시이며 최신 화면을 재촬영한 것이 아닙니다. 상세 출처는 SCREENSHOTS.md와 STORY_SOURCES.md를 확인하세요.
외부 업로드 없이 로컬에서 열 수 있습니다. 설치 파일은 https://github.com/pandabin3-code/damda-releases/releases 에서 제공합니다.
소개 자료에는 프로그램, 실제 메시지, 계정 정보가 없습니다.
