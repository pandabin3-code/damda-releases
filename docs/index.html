01

무엇을 해야 하는지

제목과 요약, 보낸 사람과 마감을 카드 하나에서 확인해요. 핵심만 간결하게 보고, 긴 내용은 눌러서 펼쳐요. 메시지 하나는 카드 하나로 모아요.

02

어디까지 진행했는지

시작 전, 진행 중, 완료, 재검토. 카드에서 상태를 바꾸면 바로 저장돼요.

03

언제 끝냈는지

완료한 시간을 기록해요. 끝낸 업무는 최근 완료순으로, 지난 업무는 월별로 돌아봐요.

원문과 편집을 함께

요약만으로 부족할 때,
원문을 바로 확인해요.

카드를 누르면 메시지 전체 내용과 편집 창이 함께 열려요. 원문을 보며 제목과 요약, 날짜를 직접 다듬을 수 있어요.

확인하고 저장한 내용으로 업무를 이어가세요.

확실하지 않은 날짜는 따로

확실하지 않은 마감은
확인 필요로 알려요.

마감이 분명하지 않으면 수신일 이후 주말과 공휴일을 제외한 5일 뒤를 제안해요. 원문을 확인하고 날짜를 확정해 주세요.

공휴일은 앱에 포함된 자료를 사용해요. 새로 지정된 임시공휴일은 업데이트가 필요할 수 있어요.

완료도 기록으로

끝낸 일을 모아 보면
지난 업무가 보여요.

최근 완료한 업무부터 확인하고, 이전 달의 업무도 월별로 찾아보세요. 완료를 취소했다가 다시 완료하면 새로운 완료 시각을 기록해요.

필요한 만큼 연결하세요

직접 만든 업무로 시작하고,
메시지도 가져와 보세요.

  1. 업무를 만들어 보세요

    쿨메신저 연결 없이도 직접 업무를 만들고 관리할 수 있어요.

  2. 연결과 기간을 선택하세요

    연결 및 설정에서 가져올 기간과 주기를 정해요. 첫 시작일은 기본 10일 전이에요.

  3. 승인하고 가져오세요

    메인 화면의 🔗 연결 버튼에서 자동 가져오기를 준비해요. 최초 한 번 승인하면 변경을 감지해 가져와요. 관리되는 PC는 전산 담당자의 설정이 필요할 수 있어요.

  4. 확인하고 진행하세요

    담당과 날짜를 확인하고, 업무에 맞게 수정한 뒤 상태를 바꿔 보세요.

내 PC 안에 저장

원문을 보관하고,
내가 수정한 업무를 지켜요.

검증한 백업 복사본에서 메시지를 가져와요. 원문과 업무는 현재 Windows 사용자 계정에 연결된 방식으로 암호화해 저장해요.

현재 판독은 로컬 규칙 기반이며 외부 AI로 메시지를 보내지 않아요. 저장 파일 복사만으로 다른 기기에 이관할 수 있는 구조는 아니에요.

문제가 생겼나요?

‘오류 보내기’에서 상황을 적으면 진단 정보를 담은 GitHub 오류 작성 화면으로 연결돼요. 메시지 원문과 보낸 사람 정보는 자동으로 포함하지 않아요.

GitHub에서 내용을 확인하고 제출해 주세요. 직접 적은 설명에도 개인정보가 없는지 확인해 주세요.

설치 파일로 시작하고, 새 버전 알림으로 개선 사항을 받아보세요. 자동 판독은 원문과 함께 확인해 주세요.

현재 설치형 베타

Windows PC에서 사용할 수 있어요

  • 업무 카드 생성·편집·검색·상태 관리
  • 선택형 쿨메신저 가져오기와 원문 확인
  • 로컬 규칙 기반 요약·종류 분류
  • 날짜 제안·확인 필요 표시와 완료 시각 기록
  • 링크·첨부파일 바로 열기, 분류 빠른 변경
  • 새 버전 알림과 설치 파일 업데이트
  • 현재 계정에 연결된 암호화 저장

Python을 따로 설치하지 않아도 돼요. WebView2가 필요하며, 설치 마법사에서 런타임 설치를 도와줘요.

후속 계획

기기와 사용 환경을 넓혀갈 예정이에요

  • 모바일 이용 경험 개선
  • 다른 기기와의 안전한 자료 연동
  • 검증 자료에 기반한 소형 모델 검토
  • 모바일 이용과 Google Drive 동기화

모바일 앱·동기화·학습된 소형 AI는 현재 제공 기능이 아니에요. PC·모바일 읽음 상태 보존을 보장하는 버전도 아니에요.

확인할 수 있는 자동 정리

왜 이렇게 정리됐는지,
근거를 함께 확인해요.

최초 판독에 사용한 원문 구간과 확인이 필요한 이유를 펼쳐 볼 수 있어요. 대상과 날짜가 맞는지 확인하고 내 업무에 맞게 다듬어 보세요.

이 설명은 처음 가져왔을 때의 분석이에요. 직접 수정한 내용의 정확성을 보증하지 않아요.

베타 0.5 · 선택해서 연결

필요한 업무를
Google 캘린더에도.

업무의 제목과 날짜·시간을 확인하고 선택한 캘린더에 등록하거나 갱신해요. 같은 업무의 중복 등록을 방지하고, Google에서 바뀐 일정은 덮어쓰기 전에 멈춰요.

담다 → Google 단방향 수동 동기화입니다. 데스크톱 OAuth 설정과 Google 로그인이 필요해요. 실제 계정 연결 검증은 별도이며 학교 계정 정책에 따라 제한될 수 있어요.

베타 0.5 후속 기능

이번 주 급식도
같은 공간에서.

학교를 선택하고 주간 식단과 영양 정보를 살펴봐요. 한 번 조회한 결과는 잠시 보관해 반복 조회를 줄여요.

나이스 정식 인증키가 필요해요. 학교가 식단을 등록하지 않은 날과 통신 오류를 구분해서 알려드려요. 실제 학교 조회는 인증키 설정 후 확인할 수 있어요.
